# Vendored Relay Design System

This folder is a copy of the components and tokens from
[relay-design-system](https://github.com/holliej0/relay-design-system),
so this prototype runs on its own with `npm install && npm run dev`.

In a real product this would be an npm package. To update the copy, run
`npm run sync-ds` with both repos cloned side by side.

The CSS is imported once in `app/layout.tsx`.
